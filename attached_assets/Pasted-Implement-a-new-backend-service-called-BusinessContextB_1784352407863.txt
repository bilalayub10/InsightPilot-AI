Implement a new backend service called BusinessContextBuilder that converts analytical results into structured business intelligence.

Create:

backend/services/business_context.py

Architecture requirements:

The service must be completely deterministic.
Do NOT call any LLM.
Do NOT use external APIs.
Use only Python.

Input:
- dataset profile
- detected business domain
- detected KPIs
- anomaly report
- chart recommendations

Output a dictionary with the following structure:

{
  "executive_summary": "",
  "strengths": [],
  "risks": [],
  "opportunities": [],
  "recommended_questions": [],
  "priority_actions": [],
  "analysis_confidence": 0,
  "dataset_quality_score": 0
}

Requirements:

1. Executive Summary
Generate a concise business summary using rule-based logic.

Example:

"Sales performance appears healthy with strong revenue indicators. Data quality is high, although missing values in Customer Region may affect geographic reporting."

2. Strengths

Generate strengths from:

high revenue

low missing values

few duplicates

high data completeness

good numeric coverage

healthy KPIs

3. Risks

Generate risks from:

missing values

duplicate rows

outliers

high skewness

few numeric columns

low dataset quality

4. Opportunities

Generate business opportunities based on detected domain.

Examples:

Sales:
- investigate top-performing products
- optimize underperforming regions
- improve conversion

Marketing:
- improve campaign ROI
- optimize acquisition channels

HR:
- reduce attrition
- improve retention

Finance:
- reduce expenses
- improve cash flow

etc.

5. Recommended Questions

Automatically generate 5 business questions.

Examples:

Why did revenue decline?

Which products contribute most profit?

Which regions underperform?

Which customers generate most revenue?

Where are anomalies concentrated?

6. Priority Actions

Return 3-5 prioritized action items.

Each item contains:

{
"title":"",
"priority":"High|Medium|Low",
"reason":""
}

7. Dataset Quality Score

Compute a score from 0-100 using:

missing values

duplicates

column diversity

row count

numeric coverage

8. Analysis Confidence

Compute a confidence score using:

business classifier confidence

number of matched KPIs

dataset quality

anomaly severity

The service must contain clean helper methods.

Do not modify frontend.

Do not modify existing services.

Only create the new service and wire it into the analyze route so the API returns the new BusinessContext object.

Follow the existing project architecture and coding style.
