Implement an Executive Intelligence "CEO Briefing" for InsightPilot.

The CEO Briefing should become the first component displayed after a dataset is analyzed.

==================================================
OBJECTIVE
==================================================

Create a concise executive summary that gives decision-makers an immediate understanding of the business.

The briefing must be generated entirely from the existing analytics engine.

DO NOT use Gemini.

DO NOT call any LLM.

Reuse existing services.

==================================================
ARCHITECTURE
==================================================

Create a new service:

services/ceo_briefing.py

This service should only compose outputs from existing services.

Reuse:

BusinessClassifier

AnalyticsService

KPIDetector

BusinessContextBuilder

AnomalyDetector

ChartPlanner

Never duplicate business logic.

==================================================
OUTPUT
==================================================

Return a JSON object.

{
  "business_domain": "",
  "confidence": 0,

  "overall_health": {
      "score": 84,
      "status": "Healthy"
  },

  "urgency": "Low",

  "biggest_risk": "",

  "top_opportunity": "",

  "priority_action": "",

  "executive_summary": "",

  "key_takeaways": [
      "...",
      "...",
      "..."
  ]
}

==================================================
BIGGEST RISK
==================================================

Generate one sentence.

Examples

Customer churn is increasing among long-term customers.

Revenue concentration is too dependent on one region.

Inventory shortages may affect fulfillment.

Employee attrition is concentrated in Engineering.

If no major risks exist, explicitly say so.

==================================================
TOP OPPORTUNITY
==================================================

Generate one actionable opportunity.

Examples

Focus marketing spend on the highest-converting channel.

Increase inventory for best-selling products.

Improve retention for premium customers.

Expand sales in the highest-margin region.

==================================================
PRIORITY ACTION
==================================================

Generate exactly ONE executive recommendation.

Begin with an action verb.

Examples

Investigate...

Increase...

Reduce...

Optimize...

Review...

==================================================
EXECUTIVE SUMMARY
==================================================

Generate 3-5 concise sentences.

Example style:

"The dataset represents a telecommunications business.

Overall data quality is high.

Customer churn appears to be the most important business issue.

Management should prioritize improving contract renewals."

==================================================
KEY TAKEAWAYS
==================================================

Return exactly three executive bullets.

Short.

Action-oriented.

No technical language.

==================================================
CONSTRAINTS
==================================================

Do not use Gemini.

Do not hardcode dataset-specific text.

Generate everything from existing analytics.

Keep all logic inside services/ceo_briefing.py.

Keep API routes thin.

Do not modify existing analytics services.

==================================================
GOAL
==================================================

The CEO Briefing should answer, within 10 seconds of uploading a dataset:

• What business is this?
• How healthy is it?
• How urgent are the problems?
• What is the biggest risk?
• What is the biggest opportunity?
• What should management do next?

The briefing should feel like the first page of a McKinsey or Deloitte executive report rather than a technical dashboard.
