Implement a complete AI Executive Report system for InsightPilot.

The goal is to allow users to generate and download a professionally formatted executive PDF report based on the uploaded dataset.

=========================================================
FEATURE
=========================================================

Add a new primary action button to the dashboard:

📄 Generate Executive Report

User flow:

1. User uploads dataset.
2. Dashboard loads completely.
3. CEO Briefing, KPIs, Charts, AI Insights and Copilot become available.
4. User clicks "Generate Executive Report".
5. Display a loading modal:

"AI is preparing your Executive Report..."

6. Generate the report.

7. Automatically download:

InsightPilot_Executive_Report.pdf

=========================================================
IMPORTANT ARCHITECTURE REQUIREMENT
=========================================================

DO NOT perform analysis again.

The report must reuse analysis that has already been produced by the application.

The Report Generator should consume existing outputs from:

• BusinessClassifier
• AnalyticsService
• KPIDetector
• ChartPlanner
• ChartInsights
• CEOBriefing
• DataQuality
• AnomalyDetector
• Copilot Context
• BusinessContextBuilder

The Report Generator is an orchestration layer only.

No duplicated business logic.

No duplicated analytics.

No duplicated KPI calculations.

=========================================================
BACKEND
=========================================================

Create:

services/report_generator.py

Create endpoint:

POST /api/report

Input:

{
    "datasetId":"..."
}

Return:

application/pdf
